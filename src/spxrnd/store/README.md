# `spxrnd.store`

Keep the raw archive safe, and make it answerable in SQL.

**Status: complete.** 86 tests, 100% statement coverage.

## The one asymmetry that shapes this component

`data/raw` cannot be rebuilt. Everything else here — Parquet, views, manifests —
is derived and can be regenerated by rerunning the pipeline. A delayed-quote
endpoint serves the present; 14:30 on a given Tuesday happens once, and a lost
capture is lost permanently.

So: **nothing mutates a capture's contents.** Compression rewrites the container,
never the bytes inside it, and every conversion is proved to round-trip before
the original is released. And **corruption must be detectable, not merely
unlikely** — hence the checksum manifest.

## Public API

### `archive` — the immutable raw layer

```python
scan(raw_dir) -> list[Capture]           # every capture, oldest first
load(path) -> dict                       # reads .json and .json.gz alike
parse_name(path) -> Capture | None       # None for non-captures, never raises
iter_payloads(raw_dir) -> Iterator[(Capture, dict)]

compress(capture, *, level=6, dry_run=False) -> CompressionResult
compress_archive(raw_dir, ...) -> list[CompressionResult]

write_manifest(raw_dir, manifest_path) -> int
verify(raw_dir, manifest_path) -> VerifyReport
```

`Capture.stem` (`_SPX_2026-08-11T20-37-03Z`) is the identity shared with the
curated layer. That shared name is what makes divergence detection a set
difference instead of a query.

**Compression is verify-then-replace**, in this order and no other:

1. compress into a temp file beside the original
2. read it back and compare to the original, byte for byte
3. only then unlink the original

A failure at any step leaves the original untouched and the temp cleaned up, so
an interrupted run is resumable rather than a half-converted archive. The error
message says explicitly that nothing was destroyed.

`verify` distinguishes **corrupted** (present, wrong digest — silent bit rot,
the serious case) from **missing** (in the manifest, gone from disk) from
**unlisted** (on disk, not in the manifest — new captures, expected).

### `schema` — the canonical row

`SCHEMA` is declared, not inferred. Inference types a column from whatever the
first file happens to contain, so a capture where every `bid_size` came back
whole becomes `int64`, the next is `float64`, and the two files no longer union.

Three decisions worth knowing:

- **`option_right`, not `right`.** `right` is SQL's `RIGHT JOIN` keyword and
  would need quoting in every query forever.
- **`expiry` is `date32`, not a string.** A string expiry is how tenor
  arithmetic quietly gets skipped.
- **Timestamps are `timestamp[ms, tz=UTC]`.** Parquet's floor is milliseconds
  and it silently promotes anything finer, so declaring `s` would leave the
  declared schema disagreeing with the file on disk.

**The store records what was served and judges none of it.** `iv == 0.0`
sentinels, zero bids, degenerate deep-ITM vols and years-stale last trades all
survive unchanged. `NULL` and `0.0` stay distinct — "not reported" and "reported
as zero" are different claims, and the iv sentinel is exactly where collapsing
them would destroy the evidence. Deciding what is *usable* belongs to `curate`,
where it is visible and reversible.

### `writer` — capture → Parquet

```python
build_table(snapshot, *, captured_at) -> (pa.Table, unparsed_count)
write_capture(capture, curated_dir, *, overwrite=True) -> WriteResult | None
```

One Parquet per capture, named for its source. Deliberate over a single
partitioned dataset because it makes the output path a pure function of the
input — so rebuilding overwrites rather than duplicates, a half-finished
backfill is repaired by rerunning, and raw/curated can be matched by name. DuckDB
globs the directory, so many files cost nothing at query time.

`captured_at` is passed in rather than read off the payload: the feed does not
know when we asked. It comes from the collector at capture time, or from the
archive filename on backfill.

Unparseable symbols are **counted and reported**, never silently dropped —
that is how a chain quietly loses an expiry. Currently zero across all 31
captures.

### `catalog` — backfill, divergence, SQL

```python
backfill(raw_dir, curated_dir, *, overwrite=True) -> BackfillReport
divergence(raw_dir, curated_dir) -> Divergence
connect(curated_dir) -> duckdb.DuckDBPyConnection
```

`backfill` never raises on a bad capture — it records it in `.failed` and keeps
going, because the other thirty are still worth converting.

`connect` returns an in-memory DuckDB with two views. In-memory on purpose: a
persisted database is a second thing that can drift from the archive, whereas
here the Parquet files are the only state. It pins `SET TimeZone='UTC'`, without
which the same query prints different wall-clock times on a laptop in Chicago
and a VM in Frankfurt.

| View | Grain |
|---|---|
| `quotes` | one row per option per capture — the full schema |
| `captures` | one row per capture — time, spot, contract/expiry/root counts |

## Divergence

Seed regression 6 was a capture that reached the raw archive and never reached
the curated layer: `_SPX_2026-08-11T23-57-57Z` had raw JSON and no CSV, and
nothing noticed. `divergence` makes that a standing check.

- `missing_curated` — archived, never converted. The seed-6 case.
- `orphan_curated` — converted, no longer archived. **Alarming**: raw is the
  source of truth and should only ever grow.

## Example

```python
from pathlib import Path
from spxrnd.store import catalog

con = catalog.connect(Path("data/curated"))
con.execute("""
    SELECT capture_utc, underlying_price, count(*) AS n
    FROM quotes WHERE expiry = '2026-08-21' AND root = 'SPXW'
    GROUP BY 1, 2 ORDER BY 1
""").fetchall()
```

### Chain of custody for the compression

`manifests/raw_archive_uncompressed.sha256` is the pre-compression manifest,
kept permanently. Compressing necessarily changes each file's digest; what must
not change is what comes back out. All 30 files were verified by decompressing
and confirming the content hashed to its original digest — the strongest
available check, and it is also a test.
